# Introduction

![Status: Planned](https://img.shields.io/badge/status-Planned-blue)

Builds the part users see: the **Draft Rooms** landing page with **Create Draft** and **Join Draft**, the two forms, guest identity in the browser, the room opening in a new tab with a bare layout, and the Tools menu link. **When this phase passes you have your MVP** ("a usable login into the draft page"). Specification: `LND-001..004`, `LND-006`, `IDN-003`, `NFR-001`, `NFR-003`, `NFR-004`.

Needs: P01 finished and the API running locally.

## 1. Requirements & Constraints

- **REQ-0201**: Implement `LND-001..004` and `LND-006`. The room page is `/tools/draft-rooms/{Code}` with a bare layout and shows only a shell (room name, code, who you are). Seats, chat and live updates come later.
- **REQ-0202**: Every UI element uses the project `Responsive*` components (`ResponsiveForm`, `ResponsiveFormField`, `ResponsiveTextBox`, `ResponsivePassword`, `ResponsiveButton`, `ResponsiveHeading`, `ResponsiveText`, `ResponsiveContainer`, `CopyButton`, `StatusMessages/*`).
- **REQ-0203**: A person who opens the room link without being a participant sees the join form inside the room page and stays in that tab (SCN-05).
- **SEC-0201**: The guest secret is stored only in local storage under one key and is never logged, never put in a URL, never shown in the UI.
- **CON-0201**: Every component has `.razor` and `.razor.cs`, and `.razor.css` when it needs styling (`blazor.instructions.md`). Logic stays in `.razor.cs`.
- **CON-0202**: Every new user-visible string goes into `Strings.resx` **and** `Strings.Designer.cs` (the file is generated by Visual Studio on save, command-line builds do not regenerate it). Prefix new keys with `DraftRooms_`.
- **CON-0203**: Forms follow `Pages/Account/Register.razor` (`ResponsiveForm` with FluentValidation).
- **GUD-0201**: Opening a new tab needs one small JS call (`ASM-12`). Keep it in an isolated, disposable module.

## 3. Alternatives

- **ALT-0201**: Open the room by a plain link only (no JS). Rejected: you asked for an automatic new tab. The fallback link covers blocked popups.
- **ALT-0202**: Store the guest identity in an HTTP cookie. Rejected (`ASM-02`): the API is another origin, local storage is already used for tokens and is shared with the new tab.

## 7. Risks & Assumptions

- **RISK-0201**: Safari and some browsers block `window.open` after an `await` (`RSK-05`). The fallback link is always shown.
- **RISK-0202**: Editing `Strings.Designer.cs` by hand is error-prone. Build after every string change, or save `Strings.resx` in Visual Studio to regenerate it.
- **ASSUMPTION-0201**: The stub `DraftRoom.razor` is not referenced by name anywhere else (the SEO and sitemap entries use the route string only).
